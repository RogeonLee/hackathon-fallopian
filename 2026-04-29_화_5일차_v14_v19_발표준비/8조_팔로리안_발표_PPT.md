# 2. 도메인 학습 — IVF의 모든 것

> "데이터를 보기 전에 도메인을 본다"

---

## 2-1. 난임이란?

- **정의**: 1년 이상 정상 부부 관계에도 임신이 안 되는 상태
- **국내 현황**: 결혼 연령 상승 → 난임 증가 추세
- **원인 분포**:
  - 여성 요인 (40%): 배란 장애, 난관 질환, 자궁내막증
  - 남성 요인 (30%): 정자 농도/운동성/형태 이상
  - 부부/원인불명 (30%)

**→ 단일 요인이 아니라 복합 요인 케이스가 많음**

---

## 2-2. IVF(체외수정) 시술 전체 프로세스

```
   [1] 호르몬 자극        →  배란 유도제 투여 (FSH, hMG)
        ↓
   [2] 난자 채취          →  성숙 난자 수집 (수집된 신선 난자 수)
        ↓
   [3] 정자 채취 + 처리   →  파트너/기증자 정자
        ↓
   [4] 수정 (IVF or ICSI) →  자연 수정 vs 미세주입
        ↓
   [5] 배아 배양 (3~5일)  →  분할기(D3) vs 배반포(D5)
        ↓
   [6] 배아 이식          →  단일/다중, 신선/동결
        ↓
   [7] 착상 확인 (2주)    →  hCG 호르몬 검사
        ↓
   [8] 임신 확인 ★ 타깃   →  심박 확인 (6~7주차)
```

## 2-6. 배아 등급 & 배양 일수

- **분할기 배아 (D3)**: 6~8세포 단계, 빠른 이식
- **배반포 배아 (D5)**: 100+세포, 자연 임신 시점에 가까움 → 착상률 ↑
- **배반포 이식 + 단일 이식 (eSET)**: 다태아 위험 ↓ + 성공률 유지

[표 6: 배양 일수 / 등급별 성공률 (참고)]

| 배양 단계 | 일수 | 평균 착상률 |
|-----------|------|-------------|
| | | |

**대회 데이터에 없는 것**: 배아 형태학적 등급(A/B/C) → 천장의 한 원인

---

## 2-7. 자가 vs 기증 (난자 / 정자)

- **자가 난자**: 환자 본인 → 환자 나이가 결정적
- **기증 난자**: 젊은 기증자 → **기증자 나이를 봐야 함**
- **기증 정자**: DI 시술 또는 IVF에서 사용

**정호님 핵심 발견 (V3)**: `real_age_num` 피처
- if 기증 난자 사용 → 기증자 나이 사용
- else → 환자 나이 사용

→ 단순한 나이 컬럼보다 강한 시그널

---

## 2-8. 우리에게 없는 변수들 — 천장의 본질

의료진이 실제로 보는데 데이터엔 없는 것:

| 결정적 변수 | 데이터에 있나 |
|------|------|
| 호르몬 수치 (FSH, LH, **AMH**, E2) | ❌ |
| **배아 형태학적 등급** (A/B/C) | ❌ |
| **자궁내막 두께** (8mm 이상 권장) | ❌ |
| 정자 운동성/형태 세부 | △ (불임 원인만) |
| 환자 BMI, 흡연/음주, 갑상선/당뇨 | ❌ |
| 시술 의사/클리닉 차이 (technique) | ❌ |
| 유전적 요인 (반복 유산 인자) | ❌ |

**→ 이 변수들이 있으면 AUC 0.78~0.82까지 가능. 없으니 0.74가 정보 한계.**

## 5-6. Adversarial Validation

**train(label=0) vs test(label=1) 이진 분류**

```
   Adversarial AUC = 0.50113  ≈  0.5
```

**해석**:
- ✅ train/test 분포 거의 동일
- ✅ Distribution shift 없음 → sample weighting 무익
- ✅ 1시간으로 큰 가설 폐기
- → OOF↔LB 갭의 원인은 shift가 아니라 **모델의 train fit**

## 5-7. 블렌딩 전략

```python
# Rank Normalization
def rank_norm(arr):
    return rankdata(arr) / len(arr)

# Nelder-Mead 다중 시작 가중치 최적화
def neg_auc(x):
    w = np.exp(x - x.max()); w = w / w.sum()
    return -roc_auc_score(y, oof_mat @ w)

for seed in range(20):
    res = minimize(neg_auc, x0=rng.normal(size=K)*0.5,
                   method="Nelder-Mead")
```

**왜 Rank Norm + NM**:
- AUC는 ranking 기반 → 절대 확률값보다 순위가 중요
- 모델별 calibration 차이 흡수
- 다중 시작으로 local optima 회피

## 7-2. Private LB 시나리오

```
Public 1위 0.74246 → Private 후퇴 가능성 ~30%
8조 LB 0.74218~0.74222 → Private 1위 점프 가능성 ~15-20%
                       → 동시 발생 시 우승 ~6-10%
```

**핵심**: 모든 모델이 corr 0.99+이라는 건 **대회 전체가 같은 천장**에 있다는 뜻
→ Public 차이가 운에 가까움 → Private이 진짜 승부

## 7-3. 핵심 발견 (정리)

[표 20: 핵심 발견 통합]

| 분야 | 발견 |
|------|------|
| 알고리즘 | raw + native categorical이 베이스 최강 |
| 앙상블 | 5-seed × 5-fold bagging이 가장 일관된 효과 |
| 자동화 | AutoGluon이 단일 모델 OOF 최강 |
| 블렌드 | rank norm + NM 자동 가중치 최적화 |
| 빠른 검증 | Adversarial Validation 1h로 큰 가설 폐기 |
| 진단 | OOF→LB 갭은 모델 종류별 시스템적 |
| 한계 | 상관계수 0.99+ = 데이터 정보 한계 |

---

## 7-4. 메타 교훈 — 다음 대회 자산 ⭐

1. **OOF→LB 갭 모델별로 재추정** — 한 갭으로 다른 모델 추정 금지
2. **상관계수 0.99+면 새 알고리즘 무익** — 데이터 정보 한계 신호
3. **OOF 향상 ≠ LB 향상** — train fit 카드 식별 필수
4. **자동 best public 룰 = 분산 최대화** — downside 자동 보호
5. **추정을 데이터로 검증하는 습관** — 3번 빗나간 패턴은 가설 정정 신호
6. **Adversarial Validation 첫 1시간** — distribution shift 빠른 검증
7. **5-seed bagging 우선 시도** — 가장 일관된 +0.0005 효과
