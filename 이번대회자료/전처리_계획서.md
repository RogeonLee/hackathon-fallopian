## 2. 전처리 전체 구조 (6단계)

```
[단계 0] Schema 정의          pipeline/schema.py     (fold 밖, 1회)
[단계 1] 컬럼 Drop            pipeline/clean_rules.py(fold 밖, 1회)
[단계 2] Dtype 변환           pipeline/clean_rules.py(fold 밖, 1회)
[단계 3] 도메인 결측 처리     pipeline/clean_rules.py(fold 밖, 1회)
[단계 4] 정합성 flag 생성     pipeline/derive.py     (fold 밖, 1회)
[단계 5] 범주 통일            pipeline/clean_rules.py(fold 밖, 1회)
──────────────── (이하 모델링 단계, fold 내부) ────────────────
Target/Freq Encoding          pipeline/encoders.py   (fold 안)
Imputer / Scaler              pipeline/encoders.py   (fold 안)
```

**원칙:** 단계 0~5는 통계 기반이 아니므로 **fold 밖에서 1회 실행**. CV 시작 시점에 train/test 모두 전처리 완료 상태여야 함.

## 4. 단계 1: 컬럼 Drop

### 4-1. 완전 drop (4개)

| 컬럼 | 분포 | 실측 신호 | 이유 |
|---|---|---|---|
| 불임 원인 - 여성 요인 | 전부 0 | — | variance=0, 정보 없음 |
| 난자 채취 경과일 | NaN 22% + 나머지 전부 0 | — | 사실상 상수 |
| **불임 원인 - 자궁경부 문제** | 0: 256,341 / 1: **10** | 10건 전부 성공 0% | 과적합 위험 (통계적 유의미성 부족) |
| **불임 원인 - 정자 면역학적 요인** | 0: 256,350 / 1: **1** | 1건 | 통계적 무의미 |

> HTML 분석(`feature_summary.html`)에서도 동일 drop 권고. §14 참조.

### 4-2. NaN→0 변환 후 flag로 활용 (3개)

베이스라인에서 그냥 두면 LGBM이 NaN으로 취급. 하지만 **1%의 시행 경험**은 신호일 수 있음.

```
착상 전 유전 검사 사용 여부  NaN → 0 (미시행),  1 유지 (시행)
PGD 시술 여부                NaN → 0,           1 유지
PGS 시술 여부                NaN → 0,           1 유지
```

→ 제출 후 feature importance 낮으면 drop, 높으면 유지.

### 5-3. 범주형 정규화 (표기 통일·희귀값 통합)

#### (A) `특정 시술 유형` 공백 정규화
실데이터에 **공백만 다른 중복 표기** 존재:
```
"ICSI / BLASTOCYST:IVF / BLASTOCYST"    → 6건
"ICSI / BLASTOCYST :IVF / BLASTOCYST"   → 4건   ← 콜론 앞 공백만 다름
"ICSI / BLASTOCYST :ICSI"               → 1건   ← 동일
```
처리:
```python
df["특정 시술 유형"] = (df["특정 시술 유형"]
    .astype(str)
    .str.replace(r"\s+", "", regex=True)   # 모든 공백 제거
    .str.replace("/", " / ")                # 슬래시 주변 단일 공백 정규화
)
```

#### (B) `배란 유도 유형` 극희귀값 통합
train에 "세트로타이드 (억제제)" 1건, "생식선 자극 호르몬" 1건만 존재. **test에는 아예 없음** → 학습 의미 無.

```python
rare = df["배란 유도 유형"].value_counts()
rare_vals = rare[rare < 10].index                       # 극희귀
df["배란 유도 유형"] = df["배란 유도 유형"].replace(
    dict.fromkeys(rare_vals, "알 수 없음")
)
```
결과: 사실상 2값 (`"기록되지 않은 시행"`, `"알 수 없음"`). Boolean `is_recorded`로 단순화 고려 가능.

## 6. 단계 3: 도메인 규칙 기반 결측 처리

**중요:** 베이스라인의 `apply_domain_rules()`는 규칙이 4개뿐. 이 계획서에서 **6종으로 확장**하고, **배아 이식 경과일 0 해석 오류도 수정**.

### 6-1. 수정: 배아 이식 경과일 0 vs NaN 구분

실제 데이터 분해:

| 상태 | 건수 | 성공률 |
|---|---|---|
| 경과일 **값 있음** (1~7일 + 0일 당일이식 포함) | 212,785 | **30.6%** |
| 경과일 **NaN** + 이식된 배아 수 == 0 (이식 안 함) | 36,535 | ≈0% |
| 경과일 **NaN** + 이식된 배아 수 == NaN (DI) | 6,291 | ≈0% |
| 경과일 NaN인데 이식된 배아 > 0 (이상) | 740 | — |

→ **NaN 전체 성공률 2.4% vs 값 있음 30.6%.** 이 차이가 가장 큰 단일 신호.

```python
# 베이스라인 (부정확): NaN을 0으로 채워서 "당일 이식(0일)"과 혼동
df.loc[mask_no_transfer, "배아 이식 경과일"] = 0

# v2 (수정):
no_transfer = df["이식된 배아 수"].fillna(0).eq(0)
df["no_transfer"] = no_transfer.astype(int)
df.loc[no_transfer, "배아 이식 경과일"] = -1     # sentinel (0일과 구분)
```

근거: `배아 이식 경과일 == 0` 케이스 24,904건은 실제로 **이식된 배아 수 > 0** (당일 이식 = zygote/pronuclear stage). 0을 "이식 없음"으로 처리하면 신호 왜곡.

### 6-2. 규칙 6종 (v2)

| # | 조건 | 대상 컬럼 | 처리 | 보조 flag |
|---|---|---|---|---|
| R1 | 시술 유형 == DI | 배아·난자·미세주입 수량 18개 | NaN → 0 | — |
| R2 | 이식된 배아 수 == 0 or NaN | 배아 이식 경과일 | NaN → -1 | `no_transfer` |
| R3 | 해동된 배아 수 == 0 or NaN | 배아 해동 경과일 | NaN → -1 | `no_frozen_transfer` |
| R4 | 해동 난자 수 == 0 or NaN | 난자 해동 경과일 | NaN → -1 | — |
| R5 | 혼합된 난자 수 == 0 or NaN | 난자 혼합 경과일 | NaN → -1 | — |
| R6 | 총 임신 횟수 == 0회 | 임신 시도 경과 연수 | NaN → -1 | `first_attempt` |

→ `pipeline/clean_rules.py`에 **규칙 테이블 dict로 선언 후 loop 적용** (architecture.md §1의 "데이터 주도" 원칙).

### 6-3. 기증자(난자/정자) 정보 — 보간 금지·구조적 결측 유지

**핵심 원칙:** "알 수 없음"에 기증자 평균 나이 등을 채워 넣으면 **안 된다.** 구조적 결측(본인 제공)을 기증 케이스와 섞으면 모델이 왜곡 학습.

#### 데이터 구조
`난자 기증자 나이 == "알 수 없음"` 242,381건의 실제 구성:

| 난자 출처 | 건수 | 의미 |
|---|---|---|
| 본인 제공 | 234,291 | **구조적 결측** (기증자가 없음) |
| 기증 제공 | 1,799 | **진짜 결측** (기증받았으나 나이 불명) |
| 알 수 없음 | 6,291 | 출처 자체 불명 (DI 시술) |

→ 96.7%는 **기증자 없음**이지 "모르는" 게 아님.

#### 발견된 강력한 신호: 고령 × 기증 난자 교호작용

| 환자 나이 | 본인 난자 | **기증 난자** | 차이 |
|---|---|---|---|
| 만18-34세 | 32.3% | 30.7% | ~0 |
| 만40-42세 | 14.4% | 32.5% | **+18%p** |
| 만43-44세 | 6.2% | **34.0%** | **+28%p** |
| 만45-50세 | 2.6% | **29.2%** | **+26%p** |

→ 고령일수록 기증 난자가 성공률을 **5배 이상** 끌어올림. 베이스라인은 이 교호작용 포착 못 함.

#### 전처리 처리 (이 단계에서 할 것)
```python
# 1) "알 수 없음"을 그대로 category 유지 (보간 금지)
```

### 8-1. `시술 시기 코드` 특별 정책 (Frequency encoding → importance 평가)

7개 익명화 코드(TRZKPL, TRDQAZ 등)로 균등 분포. HTML 분석은 "임상 의미 없음 → DROP" 권고했으나, 병원/시기 고유값 가능성 보존을 위해 **Frequency encoding 후 importance 확인** 타협안 채택.

```python
# fold 내부 (leakage 방지)
freq_map = X_tr["시술 시기 코드"].value_counts(normalize=True)
X_tr["시술_시기_freq"]  = X_tr["시술 시기 코드"].map(freq_map).fillna(0)
X_va["시술_시기_freq"]  = X_va["시술 시기 코드"].map(freq_map).fillna(0)
X_test["시술_시기_freq"] = X_test["시술 시기 코드"].map(freq_map).fillna(0)
```

**평가 기준** (§11 체크포인트에서 확인):
- 1차 제출 후 LGBM feature importance 순위
- `시술_시기_freq`가 하위 25%에 들면 → **다음 제출부터 drop**
- 상위면 유지 + Target Encoding 추가 실험

→ 원본 `시술 시기 코드` category는 **frequency encoding 대체**로 제거 (중복 방지).

#### A. 도메인 지식 (7편)

| # | 정확한 인용 | 주요 발견 (대회 관련) | 계획서 활용 |
|---|---|---|---|
| 1 | Palermo G et al. *Lancet.* 1992;340(8810):17-18 | **ICSI 기법 최초 성공** (4 임신/8 cycle) | `icsi_ratio` 개념적 근거 |
| 2 | Toner JP et al. *Fertil Steril.* 1991;55(4):784-791 | **basal FSH > age** 예측력 | 난소 예비력 프록시 개념 (우리 데이터엔 FSH 없음) |
| 3 | Templeton A, Morris JK, **Parslow W**. *Lancet.* **1996**;348(9039):1402-1406 | **대규모 36,961 cycles**: 나이 25-30세 최고 / 불임 기간↑ 성공률↓ / **시술 횟수↑ 성공률↓ (p<0.001)** / **이전 출산 유의** / **기증 난자 30+에서 p=0.04 유의** | `ever_delivered`, `repeated_3plus`, `elderly_donor_egg`의 핵심 근거 |
| 4 | Templeton A, Morris JK. *N Engl J Med.* **1998**;339(9):573-577 | **4개 초과 수정 시 2-배아 vs 3-배아 출산율 차이 없음** (OR 다태아 1.6) | `optimal_transfer = 이식==2` |
| 5 | Sunkara SK et al. *Hum Reprod.* 2011;26(7):1768-1774 | **400,135 cycles**: 난자 수 최적 ≈ **15**, 20개 초과 감소. 15개 기준 <40세 40% vs 40+ 16% | `eggs_optimal`, 나이×난자수 교호작용 |
| 6 | Domar AD et al. *Fertil Steril.* **2010**;94(4):1457-1459 | IVF dropout 원인: **스트레스 39%** (재정 아님) | `repeated_3plus` **직접 근거 아님** (간접) |
| 7 | Kawwass JF et al. *JAMA.* 2013;310(22):2426-2434 | 기증 난자 cycle 증가, 기증자 평균 28세 / 수혜자 41세. **Day-5 이식 OR 1.17, 단일 이식 OR 2.32** | `eset_blast`, `elderly_donor_egg` 핵심 근거 |

#### B. ML 예측 모델 (5편)

| # | 정확한 인용 | 우리 대회와의 관련성 |
|---|---|---|
| 8 | Goyal A et al. *PLoS One.* 2022;17(5):e0267554 | **RF (AUC 0.72) > LR (0.68)** / 상위 feature: **자극 프로토콜, 동결 배아 수, 나이** |
| 9 | Barnett-Itzhaki Z et al. *J Assist Reprod Genet.* 2020;37(10):2405-2412 (PMC7550518) | **NN AUC 0.79-0.86 > LR 0.46-0.72**. 3분위수 범주화 전처리. **이전 임신력의 광범위한 예측력 입증** |
| 10 | Hassan AA et al. *BMC Pregnancy Childbirth.* 2023 (PMC10294395) | ⭐ **우리 대회와 가장 유사**. **LGBM 주기 후 val AUC 0.816** (우리 목표 0.78-0.80과 일치). `simple deletion` 전처리로 충분. 상위 feature: maternal age, AMH, basal FSH, basal P, basal E2, infertility duration |
| 11 | Nat Commun 2025 (s41467-025-58744-z) | **센터별 특화 ML > 전국 통합 모델** (p<0.05). → `시술 시기 코드` Frequency encoding 강화 근거 |
| 12 | *Biomedicines.* 2025;13(11):2768 (PMC 41301861) | XGBoost 9-variable 모델 **internal AUC 0.876, external 78.3%**. **여성 나이 = 지배적 feature**. AMH, BMI = workhorse |

> **핵심 요약 (v2.2)**
> 베이스라인(v1) 대비 변경사항:
> - **drop 4 + flag 전환 3** (상수·희소 컬럼 정리)
> - **도메인 규칙 6종** (DI→0, no_transfer, first_attempt 등)
> - **범주 정규화** (특정 시술 유형 공백, 배란 유도 유형 희귀값 통합)
> - **복합 카테고리 분해** (특정 시술 3 flag + 배아 이유 5 flag)
> - **정합성 flag 6종**, **의도vs실제 gap flag**
> - **기증자 정보**: 보간 금지 + 사용 여부 flag (교호작용은 §13 팀원 B 단계)
> - **나이 ordinal/median 병행**
> - **시술 시기 코드 Frequency encoding → importance 평가 후 drop 결정** (Nature Comm 2025 지지)
> - **파생변수 3종 추가** (icsi_ratio / ever_delivered / repeated_3plus)
> - **v2.2: 논문 인용 검증 및 정정** — Templeton 1998 Lancet → 1996 Lancet / Toner 1991 (주제 정정) / Domar 2012 → 2010 / Royston&White 제거 / Hassan 2023·Nat Comm 2025·Biomedicines 2025 추가
>
> **현실적 AUC 목표 0.78-0.80 재확인** (Hassan 2023 LGBM 주기후 val 0.816, Biomedicines 2025 external 78.3%)
>
> `pipeline/schema.py` + `pipeline/clean_rules.py`로 구현 예정. **단계 0~5는 fold 밖에서 1회**, 인코딩/보간/스케일링은 fold 내부.
