문제 정의
  "난임 환자가 IVF(체외수정) 또는 DI(인공수정) 시술을 받았을 때,
   임신에 성공할지를 예측해라."

데이터 규모
  256,351건의 시술 기록 (한 행 = 한 번의 시도)
  양성률(성공률): 25.84%
  → 4번 시도해서 1번 성공하는 구조

평가 지표
  AUC (ROC 곡선 아래 면적)
  제출 형식: 확률값 (0~1 실수)

우리 팀 목표
  현재 베이스라인: AUC 0.74184 (LightGBM)
  목표: AUC 0.78 ~ 0.80+

규정 리스크
  이전 대회(LG Aimers) 코드와 유사도 90% 이상 시 실격
  → 디렉토리·함수·변수명을 독자적으로 재작성 필수


═════════════════════════════════════════════════════════════
  2. 우리가 받은 데이터 (69개 컬럼 개관)
═════════════════════════════════════════════════════════════

69개 컬럼을 6개 그룹으로 나누면 이해가 쉬워집니다.


그룹 1. 환자 기본 정보 (3개)
─────────────────────────────────
  시술 시기 코드    → 병원/시기 익명화 코드 (TRZKPL 같은)
  시술 당시 나이    → 구간형 (만18-34세, ..., 만45-50세, 알수없음)
  임신 경과 연수    → 마지막 임신 이후 몇 년 (96% 결측)


그룹 2. 시술 유형 (4개) — 가장 중요한 그룹
─────────────────────────────────
  시술 유형         → IVF(체외수정) vs DI(인공수정)
  특정 시술 유형    → ICSI, IVF, IUI, "ICSI:ICSI"(반복) 등 24값
  배란 자극 여부    → 난소를 약으로 자극했는지
  배란 유도 유형    → 어떤 약물을 썼는지

  핵심 발견: "특정 시술 유형"에 콜론(:)이 있으면 반복 시도
              성공률이 27%에서 7.8%로 급락


그룹 3. 불임 원인 (17개) — 단독으론 약한 그룹
─────────────────────────────────
  남성/여성/부부 주·부 불임 원인 (범주형 7개)
  불임 원인 - 난관 질환 / 남성 요인 / 배란 장애 / ... (boolean 10개)

  원인 하나하나는 상관관계 약함 (±0.01~0.04)
  → cause_count 같은 "조합 파생변수"로 써야 함


그룹 4. 과거 시술 이력 (10개)
─────────────────────────────────
  총/IVF/DI 시술 횟수
  총/IVF/DI 임신 횟수
  총/IVF/DI 출산 횟수
  클리닉 내 총 시술 횟수

  문자열 형태: "0회", "1회", ..., "5회", "6회 이상"
  → 숫자 변환 필요 (0~6) + is_censored 플래그


그룹 5. 배아/난자/정자 수량 (14개) — 두 번째로 중요
─────────────────────────────────
  총 생성 배아 수, 이식된 배아 수, 저장된 배아 수
  미세주입(ICSI) 관련 4개
  해동된 배아/난자 수, 수집/저장/혼합된 난자 수
  파트너/기증자 정자 혼합 수


그룹 6. 경과일 + 플래그 (14개) — 가장 강력한 단일 신호
─────────────────────────────────
  배아 이식 경과일  → 5일 = blastocyst = 성공률 40%
  난자 채취/해동/혼합 경과일
  배아 해동 경과일
  단일 배아 이식 여부 / 동결·신선·기증 배아 사용
  PGD/PGS 시술 여부 (99% 결측)
  대리모 여부


═════════════════════════════════════════════════════════════
  3. 결측값을 해석하는 법 (가장 중요!)
═════════════════════════════════════════════════════════════

이 데이터의 핵심은 "결측값의 종류가 다르다"는 점입니다.


결측에는 3가지 종류가 있습니다:


(A) 구조적 결측
    이유: 애초에 값이 없는 게 당연함
    예: DI 시술 → 배아 관련 컬럼 전부 NaN
        (DI는 체외수정이 아니라 배아를 만들지 않음)

    처리: NaN → 0 또는 "해당없음" 카테고리
    절대 금지: 평균으로 채우기 (가짜 데이터 주입됨)


(B) 정보 포함 결측
    이유: 결측 자체가 신호
    예: 이식된 배아 수 == 0 → 배아 이식 경과일 NaN
        → 이식 자체가 없었다는 의미 (성공률 0%)

    처리: -1 sentinel + 결측 여부 flag 생성
    이유: 모델이 "이 행은 이식 없음" 그룹으로 학습 가능


(C) 진짜 무작위 결측
    이유: 단순 기록 누락
    예: 기증 난자를 썼는데 기증자 나이를 까먹고 기록 안 함
        (1,799건만 해당)

    처리: fold 내부에서 중앙값 보간
    주의: fold 밖에서 하면 data leakage


우리 데이터의 결측 실제 분포
─────────────────────────────────
  99.4%: 난자 해동 경과일 (구조적 — 해동 난자 안 쓴 경우)
  99.2%: PGS 시술 여부 (구조적 — 99% 미시행)
  99.1%: PGD 시술 여부 (구조적)
  98.9%: 착상 전 유전 검사 (구조적)
  96.3%: 임신 경과 연수 (구조적 — 첫 시도면 없음)
  84.3%: 배아 해동 경과일 (구조적 — 신선 배아 사용 시)

  22.4%: 난자 채취 경과일 → 값은 전부 0 (variance=0 → DROP)
  21.0%: 난자 혼합 경과일 (구조적)
  17.0%: 배아 이식 경과일 (혼합 — 이식 없음 + 이상치)

   2.5%: 배아/난자 수량 관련 전체 (DI 시술 케이스)


═════════════════════════════════════════════════════════════
  4. 베이스라인의 치명적 버그
═════════════════════════════════════════════════════════════

베이스라인 코드에 이런 줄이 있습니다:

    mask_no_transfer = df["이식된 배아 수"].fillna(0).eq(0)
    df.loc[mask_no_transfer, "배아 이식 경과일"] = 0

문제: "배아 이식 경과일 = 0"의 의미가 두 가지인데 섞음

    실제 데이터에서:
      값 있음 (1~7일 포함 + 0일 당일이식): 212,785건  성공률 30.6%
      NaN (이식 안 함 / DI): 42,826건                 성공률  2.4%

    30.6% vs 2.4% — 이게 13배 차이 나는 가장 강한 신호입니다.

    근데 베이스라인은 NaN을 0(당일이식)으로 바꿔서
    "당일 이식한 사람"과 "이식 안 한 사람"을 같은 그룹으로 만듦.


v2 수정:
    no_transfer = df["이식된 배아 수"].fillna(0).eq(0)
    df["no_transfer"] = no_transfer.astype(int)   # flag 생성
    df.loc[no_transfer, "배아 이식 경과일"] = -1  # sentinel (0과 구분)


교훈:
    NaN은 "빈 값"이 아니라 "정보"입니다.
    어떤 NaN인지 분해하고, 필요하면 sentinel로 보존하세요.

  5. 전처리 철학 — 왜 HTML 제안과 다른가
═════════════════════════════════════════════════════════════

HTML 분석 파일 4개가 제공되었습니다:
  feature_summary.html
  feature_missing_detail.html
  feature_distribution.html
  correlation_heatmap.html

HTML은 통계적 관점으로 전처리를 제안:
  "결측 99% 이상 → DROP"
  "알 수 없음 → 중앙값/최빈값 대체"
  "이식 경과일 NaN → 중앙값 대체"

우리 계획서는 도메인 구조 관점:
  "99% 결측도 구조적이면 flag로 살린다"
  "알 수 없음은 sentinel로 보존 (성공률 0%면 특수 정보)"
  "이식 경과일 NaN은 가장 강한 신호 → sentinel 필수"


주요 차이점 검증 (실측 기반)
─────────────────────────────────

  HTML: 착상 전 유전 검사 → DROP
  실측: 값=1 성공률 14.8% vs NaN 26% (−11%p 차이)
  우리: NaN→0 flag로 살림 ✓

  HTML: 나이 "알 수 없음" → ordinal=3 (중앙값 대체)
  실측: 329건 성공률 0% (매우 특이한 구조적 결측)
  우리: sentinel -1 유지 ✓

  HTML: 기증자 나이 "알 수 없음" → 최빈값 대체
  실측: 242,381건 중 96.7%가 본인 난자 사용자 (기증자 없음)
  우리: category 유지, 보간 금지 ✓


수용한 HTML 제안 (좋은 것은 가져옴)
─────────────────────────────────
  - 자궁경부 문제 boolean DROP (10건만)
  - 정자 면역학적 요인 boolean DROP (1건)
  - icsi_ratio 파생변수 (Palermo 1992 근거)
  - ever_delivered 파생변수 (Templeton 1996 근거)
  - repeated_3plus 파생변수 (Templeton 1996 근거)

  시술 시기 코드 처리는 타협안 채택:
  "Frequency encoding → importance 확인 후 drop 결정"

  6. 기증자 정보 처리 — 보간 금지 원칙

질문: 기증자 정보가 "알 수 없음"인 경우 평균값으로 채우면 안 되나?

답: 절대 안 됩니다.


"알 수 없음" 242,381건의 실제 구성
─────────────────────────────────
  난자 출처 = 본인 제공:   234,291건 (기증자 자체 없음)
  난자 출처 = 기증 제공:     1,799건 (진짜 결측)
  난자 출처 = 알 수 없음:    6,291건 (출처 불명, DI 시술)

  → 96.7%는 "기증자가 모르는 게 아니라 기증자가 없는 것"


만약 기증자 평균 나이(30세)로 채우면
─────────────────────────────────
  본인 난자 사용자 234,291명에게
  "기증자 30세로부터 난자를 받았다"는 가짜 정보가 주입됨

  모델이 "모든 환자가 기증 받은 것처럼" 왜곡 학습
  성공률이 다른 두 집단(본인 26% vs 기증 32%)이 섞여버림


대신 이렇게 씁시다: 교호작용 변수 생성

  7. 처음에 놓쳤던 이슈 7가지
═════════════════════════════════════════════════════════════

데이터를 더 파니 추가로 발견된 처리 사항들:


이슈 1: 특정 시술 유형을 3개로 분해해야 함
─────────────────────────────────
  현재: 24개 카테고리로 뭉쳐 있음
  문제: "ICSI:ICSI" (성공률 1%)과 "ICSI" (27%)가 같은 컬럼에 섞임

  해결: 3개 binary flag로 분해

    has_repeat = 콜론 포함      (26% → 7.8%)
    has_blast  = BLASTOCYST 포함 (26% → 36.1%)
    has_ah     = AH 포함         (26% → 20.8%)

  추가: 공백 차이만 있는 중복 표기 존재 (ICSI / BLASTOCYST : ... 같은)
        → str.replace(r"\s+", "") 정규화 필요


이슈 2: 배아 생성 주요 이유 복합 카테고리
─────────────────────────────────
  현재: "기증용, 현재 시술용" 같은 쉼표 구분 복합값
  해결: 5개 multi-hot flag로 분해

    is_현재시술용 / is_기증용 / is_배아저장용
    is_난자저장용 / is_연구용

  NaN 6,291건은 모두 DI 시술 → "해당없음" 카테고리


이슈 3: 배아 이식 경과일 NaN 해석 오류 (이미 섹션 4 참조)


이슈 4: 단일 이식 의도 vs 실제 Gap
─────────────────────────────────
  단일 배아 이식 여부 = 0 (다중 의도)
  이식된 배아 수 = 1 (실제 1개)
  → 35,431건 발견 (중간 탈락 신호)

  파생: intended_multi_actual_single flag


이슈 5: 배란 유도 유형 사실상 2값
─────────────────────────────────
  세트로타이드 1건, 생식선 자극 호르몬 1건만 존재 (test엔 없음)
  → 희귀값을 "알 수 없음"으로 통합


이슈 6: IVF+DI 시술 횟수 != 총 시술 횟수 (가짜 모순)
─────────────────────────────────
  2,564건 모순으로 보이지만 "6회 이상" 상한 근사 때문
  → flag로 쓰면 노이즈. is_censored_total 하나로 처리


이슈 7: 수치형 극단값 (Outlier)
─────────────────────────────────
  배아 51개, 난자 51개까지 있음 (p99=20)
  → 트리(LGBM)는 robust하니 지금은 OK
  → MLP 추가 시 log1p 또는 winsorize(p99) 적용

  8. 논문 12선이 우리에게 말해주는 것
═════════════════════════════════════════════════════════════

전처리·파생변수의 논문 근거를 검증한 결과 (할루시네이션 제거):


A. 도메인 지식 논문 (1991~2013)
─────────────────────────────────

  Palermo 1992 Lancet
    → ICSI 기법 최초 성공 보고
    → 우리의 "미세주입된 난자 수" 관련 컬럼의 의미 제공

  Toner 1991 Fertility and Sterility
    → basal FSH가 나이보다 더 좋은 예측인자
    → 우리 데이터엔 FSH 없음 → "수집된 신선 난자 수"로 프록시

  Templeton 1996 Lancet (36,961 cycles)
    → 나이 25-30세 최고 성공률
    → 시술 횟수↑ 성공률↓ (p<0.001)
    → 이전 출산 경험은 유의한 긍정 인자
    → 30세 이상에서 기증 난자가 유의하게 높은 성공률
    → 파생변수 ever_delivered, repeated_3plus의 근거

  Templeton & Morris 1998 NEJM
    → 4개 초과 수정 시 2-배아 vs 3-배아 출산율 차이 없음
    → 3-배아는 다태아 위험만 증가
    → 파생변수 optimal_transfer = (이식==2)

  Sunkara 2011 Human Reproduction (400,135 cycles)
    → 난자 수 최적 = 약 15개
    → 15개 기준 40세 미만 40% vs 40세 이상 16%
    → 파생변수 eggs_optimal, eggs_x_age

  Domar 2010 Fertility and Sterility
    → IVF dropout 주 원인: 스트레스 39%
    → 반복 시술의 직접 근거는 아님 (Templeton 1996이 더 적절)

  Kawwass 2013 JAMA
    → 기증 난자 주기 증가 (10,801 → 18,306)
    → Day-5 이식 OR 1.17, 단일 이식 OR 2.32
    → 파생변수 eset_blast (단일 + blastocyst) 핵심 근거


B. ML 예측 모델 논문 (2020~2025)
─────────────────────────────────

  Goyal 2022 PLOS ONE
    → Random Forest AUC 0.72 > Logistic Regression 0.68
    → 상위 feature: 자극 프로토콜, 동결 배아 수, 나이

  Barnett-Itzhaki 2020
    → Neural Network AUC 0.79-0.86 > LR 0.46-0.72
    → 이전 임신력의 광범위한 예측력 입증

  Hassan 2023 BMC Pregnancy Childbirth ⭐ 우리 대회와 가장 유사
    → LGBM 주기 후 validation AUC 0.816
    → "simple deletion + 민감도 분석"으로 충분

    → 우리 목표 0.78-0.80의 직접 근거

  Nature Communications 2025

  Biomedicines 2025 (XGBoost, Szeged Univ)
    → 9-variable 모델 internal AUC 0.876
    → External validation 78.3%
    → 여성 나이 = 지배적 feature, AMH·BMI = workhorse

═════════════════════════════════════════════════════════════
  9. 의학 용어 쉬운 해설
═════════════════════════════════════════════════════════════

IVF (In Vitro Fertilization) = 체외수정
  난자와 정자를 몸 밖(시험관)에서 수정시켜 배아를 만들고 자궁에 이식


DI (Donor Insemination) = 기증 정자 인공수정
  기증자 정자를 자궁 안에 직접 주입
  체외수정이 아니므로 배아 관련 컬럼 대부분 의미 없음


ICSI (Intracytoplasmic Sperm Injection) = 미세주입
  정자 1마리를 난자에 현미경으로 직접 주입하는 기법
  주로 남성 요인 불임 (정자 수 적음/운동성 낮음/형태 이상)에 사용
  우리 데이터의 "미세주입된 난자 수" 등 4개 컬럼이 ICSI 관련


IVF cycle = 치료 한 주기
  1 cycle = 약 4~6주 소요
    1주차: 난소 자극 주사 → 난포 성장
    2-3주차: 난자 채취 → 체외 수정 → 배아 배양
    3주차: 배아 이식
    5주차: 임신 확인

  한 환자가 여러 cycle 받을 수 있음
  → "총 시술 횟수"가 이런 cycle 수


Basal FSH (기저 난포 자극 호르몬)
  생리 주기 2-3일차에 측정한 혈중 FSH 농도
  FSH가 높을수록 난소 기능 저하

  임상 기준:
    < 10 mIU/mL: 정상
    10~15: 저하 우려
    > 15: 심각한 저반응


나이 × 난자 수 교호작용
  같은 난자 개수라도 나이에 따라 성공률이 다름
  예: 15개 난자 기준
      40세 미만: 성공률 40%
      40세 이상: 성공률 16%

  왜? 난자 "개수"는 비슷해도 "질"(염색체 정상성)이 다름
    25세 난자: 염색체 이상 10-15%
    40세+ 난자: 염색체 이상 50%+

  → 파생변수 eggs_x_age = 난자수 × 나이_ord


HFEA (Human Fertilisation and Embryology Authority)
  영국 정부 기관, 1990년 설립
  영국 내 모든 IVF·DI 시술 의무 등록
  세계 최대 규모 IVF 데이터베이스

  Templeton 1996은 HFEA 36,961 cycle 분석
  Sunkara 2011은 HFEA 400,135 cycle 분석


Maternal age = 시술 받는 여성의 나이
  우리 데이터의 "시술 당시 나이"
  논문에서 가장 중요한 단일 예측 feature


주요 호르몬 정리

  FSH  = 난포 자극 호르몬 (난소 반응 지표)
  LH   = 황체 형성 호르몬 (배란 유도)
  PRL  = 프로락틴 (모유 관련, 높으면 배란 방해)
  E2   = 에스트라디올 (여성 호르몬, 난포 성장)
  P    = 프로게스테론 (착상·임신 유지)
  AMH  = 항뮬러관호르몬 (난소 예비력 최고 지표)

  → 우리 데이터엔 호르몬 값 전혀 없음
  → 난자 수 등으로 프록시 접근


배아 발달 단계 (매우 중요!)

  0일차: zygote (수정란)
  2-3일차: cleavage stage (분열 중)
  5-6일차: blastocyst (배반포) ← 성공률 최고

  우리 데이터 "배아 이식 경과일"이 이 단계를 나타냄
  → 파생변수 blast_transfer = (경과일 >= 5)


Gn (Gonadotropin) = 배란 유도용 호르몬 주사
  Gn 용량이 많다 = 난소 반응 약함
  → 우리 데이터엔 용량 정보 없음


HCG (Human Chorionic Gonadotropin) = 임신 호르몬
  임신 확인용 혈액 검사 지표
  → 이게 있으면 이미 임신이므로 우리 대회 예측 대상 아님


보간 (Imputation) = 결측값 채우기
  방법별 장단점:
    중앙값 대체: 간단, 이상치 영향 적음 / 정보 손실
    평균 대체: 간단 / 이상치에 취약
    최빈값 대체: 범주형 적합 / 왜곡 가능
    -1 sentinel: 트리 모델이 "결측 그룹"으로 학습 / 수치 왜곡 위험
    missForest: 랜덤포레스트로 예측 / 정확 / 느림
    MICE: 여러 번 보간 후 평균 / 불확실성 반영 / 복잡

  우리 전략:
    구조적 결측 → sentinel or "해당없음" 카테고리
    진짜 무작위 결측 → fold 내부 중앙값 (leakage 방지)


═════════════════════════════════════════════════════════════
 10. 프록시(Proxy) 개념
═════════════════════════════════════════════════════════════

프록시란?
  원래 알고 싶은 값이 데이터에 없거나 측정 어려울 때,
  그 값을 간접적으로 대신해 줄 수 있는 다른 값.

일상 예시:
  알고 싶은 것              →  프록시
  ─────────────────────────────────────────
  사람의 건강 상태          →  BMI, 걸음 수, 심박수
  도시의 경제 활성도        →  야간 위성사진 불빛 밝기
  학생의 학습 태도          →  도서관 이용 시간, 출석률
  식당의 인기               →  대기줄 길이, 구글 리뷰 수

공통점: 100% 정확하진 않지만 강한 상관관계로 대체 가능


이 대회의 핵심 프록시 전략
─────────────────────────────────

  논문이 요구하는 것          우리 대회 프록시
  ─────────────────────────────────────────────────────
  AMH, 기저 FSH            →  수집된 신선 난자 수
  난자 질                   →  시술 당시 나이
  BMI                      →  (프록시 없음, 포기)
  자궁내막 두께            →  이식된 배아 수 > 0 간접 증거
  정자 질                   →  불임 원인 - 정자 농도/운동성/형태
  병원 숙련도              →  시술 시기 코드 frequency
  난소 반응                 →  배란 자극 여부 + 난자 수

핵심: 못 가진 데이터의 빈자리를, 가진 데이터로 영리하게 메우는 기법


═════════════════════════════════════════════════════════════
 11. LightGBM을 베이스라인으로 쓰는 이유
═════════════════════════════════════════════════════════════

1. 표 형식 데이터에서 압도적 성능
   이미지/텍스트가 아닌 정형 데이터
   정형 데이터에선 딥러닝보다 Gradient Boosting이 거의 이김

2. 결측값·범주형을 네이티브로 처리
   전처리 없이 범주형 그대로 넘겨도 됨
   NaN도 자체 처리

3. 빠른 학습 속도
   256K행을 5-fold CV로 돌려도 몇 분 내 완료
   해커톤 시간 압박에 적합

4. Feature Importance 해석 가능
   어떤 피처가 중요한지 바로 확인
   전처리 결과 검증, 파생변수 효과 측정

5. 이 대회와 직접 유사한 논문의 검증
   Hassan 2023: LGBM이 첫 주기 IVF 예측 AUC 0.816
   XGB, RF보다 robust
