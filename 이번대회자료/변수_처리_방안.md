# 👤 01. 시술 시기 코드

**이게 뭔가요?**
어느 병원/시기에 시술했는지를 나타내는 **익명화된 7자리 코드**. `TRZKPL`, `TRDQAZ` 같은 형태로 7개 유니크 값이 있어요.

**데이터에 어떤 값이 있나요?**
7개 코드가 각각 34,000~38,000건씩 **거의 균등하게** 분포돼 있어요.

**우리는 어떻게 처리하나요?**
🟡 **Frequency Encoding** 적용 → LGBM 학습 → **Feature importance 하위 25%면 DROP**

**왜 그렇게 하나요?**
HTML 분석은 "익명 코드니까 그냥 버려"라고 했어요. 하지만 Nature Communications 2025 논문이 **"센터별 특화 모델이 전국 통합 모델보다 성능 우수(p<0.05)"**라고 증명했습니다.

병원마다 숙련도·장비·환자 풀이 다르니 시기 코드가 **"병원 숙련도 프록시"**가 될 수 있어요. 그래서 바로 버리지 말고, frequency로 바꿔서 학습 한 번 돌리고 **결과 보고 결정**합니다.

# 👶 02. 시술 당시 나이

**이게 뭔가요?**
시술 받은 여성의 나이. 연속 숫자가 아니라 **구간형**이에요.

**데이터에 어떤 값이 있나요?**
```
만18-34세:   102,476건 (성공률 32.3%)
만35-37세:    57,780건 (성공률 27.8%)
만38-39세:    39,247건 (성공률 21.7%)
만40-42세:    37,348건 (성공률 15.9%)
만43-44세:    12,253건 (성공률 11.8%)
만45-50세:     6,918건 (성공률 16.8%)
알 수 없음:      329건 (성공률  0.0%) ⚠
```

**우리는 어떻게 처리하나요?**
✅ **Ordinal + Median 병행 생성**
```
ord: 0→5까지 숫자 등급
med: 중앙값 (만18-34→26.0, 만35-37→36.0, ...)
알 수 없음 → ord=-1 (sentinel)
```

**왜 그렇게 하나요?**
이건 **이 대회에서 가장 강력한 단일 예측인자**입니다 (Templeton 1996, Biomedicines 2025).

왜 2개 버전을 만드냐면:
- `ord`: "1등급 차이"의 순서 정보
- `med`: "나이 5살 차이"라는 **거리 정보**

모델이 둘 다 보고 더 유용한 걸 쓰게 합니다.

"알 수 없음" 329건은 **성공률 0%**인 매우 특이한 그룹. HTML은 "이걸 3(중앙값)으로 채우자" 했는데, 그러면 **실패 그룹이 평범한 그룹으로 둔갑**해서 정보 소실. 그래서 sentinel `-1`로 따로 둡니다.

**💡 파생변수 힌트:**
- `elderly = (나이_ord >= 3)` — 만40세 이상
- `age_median` 자체가 다른 변수와 곱하기 교호작용에 유용

# 🔄 03. 임신 시도 또는 마지막 임신 경과 연수

**이게 뭔가요?**
직전 임신(또는 시도) 이후 몇 년이 지났는지. **96.3%가 결측**.

**왜 이렇게 결측이 많나요?**
첫 시도 환자는 "이전 임신"이 없으니 값이 없는 게 당연해요. 구조적 결측입니다.

**우리는 어떻게 처리하나요?**
✅ NaN → -1 (sentinel) + `first_attempt` flag 생성

**왜 그렇게 하나요?**
HTML은 "결측 96%라 DROP"이라고 했어요. 하지만 실측 결과:
- NaN 성공률: 26.0% (첫 시도거나 이전 기록 없음)
- 값 있음: 21.7% (이전 임신 경험 있음)

**4%p 차이**나는 유의한 신호. 더 중요한 건 **"첫 시도인지 여부"** 그 자체가 정보예요.

**💡 파생변수:**
- `first_attempt = (총 임신 == 0)` — 더 직접적 신호
- `long_infertility = (임신 경과 연수 >= 7)` — Templeton 1996에서 유의

# 🧬 05. 특정 시술 유형 ⭐⭐⭐ 가장 중요한 컬럼 중 하나

**이게 뭔가요?**
ICSI, IUI 같은 **세부 기법**. 24개 유니크 값이 있어요. `ICSI:ICSI`처럼 콜론 포함된 값도 있습니다.

**데이터에 어떤 값이 있나요?** (상위)
```
ICSI:               122,368건 (성공률 27.3%)
IVF:                 91,755건 (26.1%)
Unknown:             26,939건 (23.7%)
IUI:                  6,100건 (12.9%)
ICSI:ICSI:            2,314건 ( 1.0%) ⚠ 반복 시도
ICSI/BLASTOCYST:      1,609건 (35.7%) ⬆
IVF/BLASTOCYST:       1,248건 (36.6%) ⬆
IVF:IVF:              1,146건 ( 1.0%) ⚠ 반복 시도
```

**우리는 어떻게 처리하나요?**
✅ **공백 정규화** + **3개 binary flag로 분해**
```
has_repeat = ":" 포함       (성공률 26% → 7.8%)
has_blast  = "BLASTOCYST" 포함 (26% → 36.1%)
has_ah     = "AH" 포함         (26% → 20.8%)
```

**왜 그렇게 하나요?**
24개 카테고리로 뭉쳐 있으면 **신호가 희석**됩니다. 예를 들어 "ICSI / BLASTOCYST"라는 값은 "ICSI였다"는 정보와 "blastocyst 이식"이라는 정보를 동시에 가지는데, 모델은 그걸 하나의 묶음으로만 봐요.

3개 flag로 분해하면:
- 반복 시도 여부 (성공률 1/4로 감소!)
- Blastocyst 여부 (성공률 1.4배 증가)
- AH(부화 보조) 여부 (어려운 케이스 표시)

각각 독립적으로 학습됩니다.

**추가 함정:** 공백 차이만 있는 중복 표기가 있어요.
```
"ICSI / BLASTOCYST:IVF / BLASTOCYST"    (6건)
"ICSI / BLASTOCYST :IVF / BLASTOCYST"   (4건) ← 콜론 앞 공백만 다름
```
→ `str.replace(r"\s+", "")` 등으로 정규화 필수.

# 🧪 08. 단일 배아 이식 여부

**이게 뭔가요?**
**1개 배아만 이식하기로 계획했는가** (0/1). 쌍둥이 위험을 줄이기 위한 현대 권장 방식.

**데이터에 어떤 값이 있나요?**
```
0 (다중): 191,677건 (성공률 22.9%)
1 (단일):  58,383건 (성공률 36.7%) ⬆
NaN:        6,291건 (DI 케이스)
```

**우리는 어떻게 처리하나요?**
✅ Int8 유지 + NaN은 중앙값으로 (fold 내부)

**왜 그렇게 하나요?**
단일 이식이 오히려 성공률 **1.6배 높음!** 왜 이럴까요?

실제로는 **"양질의 배아 1개를 고를 수 있을 만큼 상태가 좋은 케이스"**가 단일 이식을 선택하기 때문. 다중 이식은 "배아 질이 부족해서 여러 개 넣어서 확률 올리자" 전략인 경우가 많아요.

즉 **원인과 결과의 역전**. 이런 통계적 특이점을 모델이 학습합니다.

**💡 핵심 파생변수:**
- `eset_blast = (단일 이식 == 1) AND (blastocyst)` — Kawwass 2013에서 최고 조합 (OR 1.17 × 2.32)
- `intended_multi_actual_single = (단일==0) AND (이식==1)` — 의도와 실제가 다른 "중간 탈락" 케이스

# 🧬 09. 착상 전 유전 검사 사용 여부

**이게 뭔가요?**
배아의 유전적 이상을 착상 전에 검사했는지. **98.9% 결측** (사실상 미시행이 대부분).

**우리는 어떻게 처리하나요?**
✅ **NaN → 0 (미시행), 1은 유지 (시행)**

**왜 그렇게 하나요?**
HTML은 "99% 결측이니 DROP"이라 했어요. 하지만 실측:
- 값=1인 케이스 성공률: **14.8%**
- NaN 케이스 성공률: 26.0%
- **-11%p 차이!**

왜 검사받은 사람이 더 실패할까요? **검사가 필요할 만큼 어려운 케이스**(고령·반복 실패)만 이 검사를 받기 때문. 즉, 검사 받음 = "힘든 케이스" 마커.

NaN→0 변환하면 1%가 "검사 받음"이라는 좋은 flag가 됩니다.

# 🔬 18-27. 불임 원인 Boolean 세부 (10개)

난관 질환, 남성 요인, 배란 장애, 여성 요인, 자궁경부 문제, 자궁내막증, 정자 농도/면역학적/운동성/형태 boolean.

**우리는 어떻게 처리하나요?**

### ❌ DROP 3개
```
21. 불임 원인 - 여성 요인        (전부 0, variance=0)
22. 불임 원인 - 자궁경부 문제    (1이 10건만, 과적합 위험)
25. 불임 원인 - 정자 면역학적 요인 (1이 1건만, 통계적 무의미)
```

### ✅ 유지 7개
난관, 남성, 배란, 자궁내막증, 정자 농도, 정자 운동성, 정자 형태

**왜 그렇게 하나요?**
"자궁경부 문제" 10건 중 10건 전부 성공 0%는 신호처럼 보이지만, **10건은 너무 적어서** 모델이 과적합할 위험이 더 큽니다. "정자 면역학적" 1건은 말할 것도 없고요.

**💡 파생변수 (Templeton 1996: 단독 약함, 조합 필수):**
```
cause_count = sum(남은 7개 boolean)           # 원인 다중성
female_factor_strong = (난관+배란+자궁내막증 >= 2)
male_factor_severe   = (정자 농도+운동성+형태 >= 2)  # Palermo 1992
```

# 🔢 29-38. 시술·임신·출산 횟수 (10개 — 문자열 숫자)

**이게 뭔가요?**
총/IVF/DI별로 시술 횟수, 임신 횟수, 출산 횟수. 전부 **"0회", "1회", ..., "6회 이상"** 형태.

**데이터에 어떤 값이 있나요?**
각 컬럼마다 7개 유니크 값 (0회~6회 이상).

**우리는 어떻게 처리하나요?**
✅ 문자열 → 정수 변환 + `is_censored` flag
```
"0회"     → 0
"1회"     → 1
...
"5회"     → 5
"6회 이상" → 6     + is_censored_{col} = 1  (상한 도달 표시)
```

**왜 그렇게 하나요?**
"6회 이상"은 **실제론 6회일 수도, 10회일 수도 있음**. 그냥 6으로 넣으면 정보 손실. `is_censored` flag를 같이 달면 "이 값은 상한 도달이라 실제론 더 클 수 있다"를 모델이 알게 돼요.

**💡 핵심 파생변수:**
```
is_first_attempt  = (총 시술 == 0)        # Templeton 1996
repeated_3plus    = (총 시술 >= 3)        # Templeton 1996 (p<0.001)
ever_delivered    = (총 출산 > 0)         # Templeton 1996, Barnett-Itzhaki 2020
                                            ⭐ 이전 출산 경험은 강한 긍정 신호!
prev_birth_rate   = 총 출산 / (총 임신 + 1)
```

# 🥚 39-52. 배아/난자/정자 수량 (14개 — 수치형)

**이게 뭔가요?**
총 생성 배아 수, 이식된 배아 수, 저장된 배아 수, 미세주입 관련 4개, 해동된 배아/난자, 수집/저장/혼합 난자, 파트너/기증자 정자 혼합 수 등.

**데이터에 어떤 값이 있나요?**
- 최대값 51 (배아나 난자가 최대 51개까지)
- p99 ≈ 20, p99.9 ≈ 30
- 결측률 2.5% (전부 DI 케이스)

**우리는 어떻게 처리하나요?**
✅ **R1 규칙: DI → 0** (구조적 결측) + 나머지는 fold 내부 중앙값

**왜 그렇게 하나요?**
DI 시술은 체외수정이 아니라 배아 자체를 안 만들어요. 그러니 "배아 수 = NaN"이 아니라 실질적으로 **"배아 수 = 0"**. 이걸 0으로 명시하면 모델이 올바르게 학습.

**💡 엄청 중요한 파생변수들:**

### 비율 변수 (Palermo 1992, Templeton 1998)
```
icsi_ratio       = 미세주입 생성 배아 / (총 생성 배아 + 1)  # ICSI 효율
fertilize_yield  = 미세주입 생성 / (미세주입 난자 + 1)      # 수정 효율
transfer_density = 이식된 배아 / (총 생성 배아 + 1)         # 이식 집중도
freeze_ratio     = 저장된 배아 / (총 생성 배아 + 1)         # 여분 배아 여유
```

### 난자 수 기반 (Sunkara 2011: 최적 ≈ 15개)
```
eggs_optimal        = (수집 신선 난자 10~20)   # 최적 구간
eggs_excess         = (수집 신선 난자 > 20)    # 과자극 역효과
low_ovarian_response = (수집 신선 난자 <= 3)   # 저반응 (FSH 프록시)
eggs_x_age          = 난자 수 × 나이_ord       # 핵심 교호작용
```

### 이식 배아 수 (Templeton & Morris 1998 NEJM)
```
optimal_transfer = (이식된 배아 수 == 2)   # 4개 초과 수정 시 최적
over_transfer    = (이식된 배아 수 >= 3)   # 다태아 위험만 증가
```


✅ **Category 그대로 유지. 절대 보간 금지.**

**왜 그렇게 하나요?**
만약 "알 수 없음"에 기증자 평균 나이(30세)를 채우면:
- 본인 난자 사용자 234,291명에게 "기증자 30세로 받았다"는 **가짜 정보 주입**
- 모델이 "모두가 기증 받은 것처럼" 왜곡 학습
- 본인(26%) vs 기증(32%) 성공률이 섞여서 정보 상실

```
나이          본인 난자    기증 난자    차이
───────────────────────────────────────

만35-37세     27.7%        31.8%       +4%p

만40-42세     14.4%        32.5%      +18%p
```

**💡 이것 때문에 만드는 핵심 파생변수:**

```
used_donor_egg    = (난자 출처 == "기증 제공")
used_donor_sperm  = (정자 출처에 "기증" 포함)
⭐ elderly_donor_egg = (나이_ord >= 3) & used_donor_egg  ← Kawwass 2013 근거
```

### 63. 난자 채취 경과일 ❌ DROP

### 64. 난자 해동 경과일 (99.4% NaN)

### 65. 난자 혼합 경과일 (21% NaN)

### 66. 배아 이식 경과일 🌟🌟🌟 대회 최강 단일 신호

**이게 뭔가요?**
배아가 며칠간 배양된 후 이식됐는지. 배아 발달 단계의 지표.

**데이터에 어떤 값이 있나요?**
```
0일 (당일 이식):    24,904건 (성공률 25.1%)
1일:                 6,053건 (18.7%)
2일 (cleavage):     35,078건 (21.2%)
3일 (cleavage):     57,924건 (25.9%)
4일:                 4,504건 (34.4%)
5일 (blastocyst):   81,459건 (40.4%) ⭐ 최고
6일 (blastocyst):    2,773건 (30.0%)
7일:                    90건 (41.1%)
NaN:                43,566건 ( 2.4%) ← 이식 안 함
```

**우리는 어떻게 처리하나요?**
✅ **R2 규칙: NaN → -1 sentinel + `no_transfer` flag**

**⚠ 베이스라인 버그 수정:**
```
# 베이스라인 (잘못됨):
df.loc[mask_no_transfer, "배아 이식 경과일"] = 0
# → NaN과 0일(당일이식)이 섞여버림

# v2 (정확):
no_transfer = df["이식된 배아 수"].fillna(0).eq(0)
df["no_transfer"] = no_transfer.astype(int)
df.loc[no_transfer, "배아 이식 경과일"] = -1  # sentinel (0과 구분)
```

**왜 그렇게 하나요?**
값 있음 30.6% vs NaN 2.4% — **13배 차이**. 이 신호를 섞으면 정보 파괴.

**💡 가장 강력한 파생변수:**
```
⭐ blast_transfer    = (배아 이식 경과일 >= 5)     # Kawwass 2013
cleavage_transfer    = (배아 이식 경과일 in {2,3})
no_transfer          = (이식된 배아 수 == 0)        # 성공률 0% 케이스
```

### 67. 배아 해동 경과일 (84.3% NaN)
**처리:** R3 규칙 — 해동 배아 수 = 0 → -1 sentinel + `no_frozen_transfer` flag.
신선 배아 vs FET(해동) 구분의 중요 지표.
