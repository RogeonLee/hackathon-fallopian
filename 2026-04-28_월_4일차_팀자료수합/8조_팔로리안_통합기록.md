## 5. 8조 통합 핵심 발견 ✅

### 알고리즘 발견
1. **raw + LGBM native categorical이 베이스 최강** — 파생변수는 train fit 위험
2. **5-seed × 5-fold bagging의 강력함** — 정호님 V3가 단일 시드 0.7398 → 5-seed 0.74045 (+0.00047)
3. **AutoGluon이 단일 OOF 최강** — ag_raw_10h 0.74126 (v8 +0.00047)
4. **rank normalization + weighted blend** — 단순 평균/스태킹보다 우위
5. **Adversarial Validation으로 빠른 가설 폐기** — AUC 0.501로 shift 없음 (1시간)

### 메타 발견 ⭐
1. **OOF→LB 갭은 모델 종류별 시스템적**
   - v8 raw LGBM: +0.00129 ← 정상
   - 정호님 V3 (5-seed LGBM): **+0.00156** ← 더 큼 (LGBM 다중시드 효과)
   - AG 추가: +0.00099 (-0.00030)
   - pseudo 추가: -0.00081 (-0.00210)

2. **상관계수 0.99+ = 알고리즘 다양화 한계** — 8종 모델 모두 같은 시그널 학습

3. **OOF 향상 ≠ LB 향상** — 정호님 V11 / 로건님 NM safe 4way 모두 검증

4. **자동 best public 룰 = 분산 최대화** (downside 안전카드 자동 보호)

5. **3번 연속 빗나간 패턴 → 가설 정정 습관 필수**

### 도메인 발견
- **`real_age_num`**: 기증 난자면 기증자 나이를 사용 (정호님 V3 핵심 피처)
- **나이가 결정적 변수**: 비선형 효과 (20대 35-45% → 43+세 5%)
- **FET vs 신선 주기 분리** 필요
