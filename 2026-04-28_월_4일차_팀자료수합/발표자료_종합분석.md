# 해결
def _to_cat(df):
    for c in df.columns:

## 📈 성공 요인 분석

### Algorithm 측면
✅ **5-seed × 5-fold bagging의 강력함**
  - 정호님 V3: 단일시드 0.7398 → 5-seed 0.74045 (+0.00047)
  - 가장 일관되고 안정적인 성과

✅ **AutoGluon 단일 모델 최강**
  - ag_raw_10h: OOF 0.74126 (v8 +0.00047)
  - 자동 모델 선택의 강력함

✅ **Rank normalization + weighted blend**
  - 단순 평균/스태킹보다 안정적
  - Nelder-Mead 가중치 최적화

✅ **Raw data + LGBM native categorical 최강**
  - 파생변수는 train fit 위험
  - 범주형을 그대로 유지하는 것이 최적

### Meta 측면
✅ **데이터 누수 방지 설계**
  - Target Encoding: 5-Fold OOF 방식
  - fit은 반드시 train only
  - test 예측 = fold 평균

✅ **자동 best 룰 활용**
