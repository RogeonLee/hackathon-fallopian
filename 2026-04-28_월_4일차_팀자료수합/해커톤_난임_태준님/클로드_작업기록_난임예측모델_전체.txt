[신규 2개 — Gemini + 산부인과 전문의 의견 종합]
  - age_normalized_efficiency : 배아생성효율 × (35/나이)
    ※ 수식 방향 수정: ×(나이/35) → ×(35/나이)
    ※ 고령인데 효율 높음 = 강한 긍정 신호 (상관 0.063→0.087)

  - is_elective_SET : (이식된 배아 수 == 1) & (총 생성 배아 수 > 1)
    ※ 선택적 단일 배아 이식 성공률: 38.0%
    ※ 어쩔 수 없는 단일 이식 성공률: 11.1%
    ※ 27%p 차이 — 배아 품질 선별 신호의 핵심

[Step 4] main.py — 6모델 앙상블 구조
────────────────────────────────────────────────────────────────

[모델 구성]
  M1. LightGBM v3   (SEEDS_5=[42,2024,777,31415,99999], 5-Fold)
  M2. LightGBM v3+TE (SEEDS_5, 시술 시기 코드 Target Encoding)
  M3. XGBoost v3    (SEEDS_3=[42,2024,777], 5-Fold)
  M4. XGBoost full  (SEEDS_3, enable_categorical=True, X_fc 피처셋)
  M5. LGB split     (SEEDS_5, 이식/비이식 분리 학습)
  M6. CatBoost full (SEEDS_3, max_ctr_complexity=2)

[파라미터]
  LGB: learning_rate=0.025, num_leaves=95, min_data_in_leaf=150
       num_boost_round=5000, early_stopping=120
  XGB: learning_rate=0.03, max_depth=7, min_child_weight=10
       num_boost_round=3000, early_stopping=100
  CAT: iterations=600, learning_rate=0.05, depth=6
       max_ctr_complexity=2, early_stopping=100

[데이터 누수 방지 설계]
  - fit은 반드시 train only
  - Target Encoding: 5-Fold OOF 방식 (val 통계 절대 미사용)
  - 앙상블 가중치: OOF 예측에서만 scipy.optimize Nelder-Mead 탐색
  - test 예측 = fold 평균 (OOF 통계 사용 안 함)

■ 에러 해결 이력
================================================================

[에러 1] TypeError: '>' not supported between 'str' and 'int'
  원인: pandas 2.0+ StringDtype 유지 문제
  해결: safe_num() 헬퍼 + pd.to_numeric() 추가

[에러 2] ValueError: pandas dtypes must be int, float or bool
  원인: string 컬럼이 LGB에 들어감
  해결: finalize_features()에서 횟수형/범주형 자동 분류 처리

[에러 3] CatBoostError: Cannot convert 'ICSI' to float
  원인: cat_idx_full이 KEEP_CAT_FULL 목록만 포함 (나머지 string 누락)
  해결: finalize 후 실제 string 컬럼 전체 자동 탐색으로 변경

[에러 4] XGBoost KeyError: 'str'
  원인: _to_cat()에서 pandas 2.0 str dtype 미탐지
  해결: pd.api.types.is_numeric_dtype()으로 비수치형 전체 탐지

■ 핵심 임상 인사이트 (산부인과 전문의 관점)
================================================================

1. 배반포 이식 (has_BLASTOCYST, 성공률 36.1%)
   → 5일 배양 생존 = 배아 생존력의 직접 증거
   → 단순 이식 방법 차이가 아닌 배아 품질 선별 과정

2. 선택적 단일 배아 이식 (is_elective_SET, 38.0% vs 11.1%)
   → 배아 여럿 중 1개 선택 = 냉동 보관 가능한 잉여 배아 존재
   → 어쩔 수 없는 단일 이식과 근본적으로 다른 상황

3. age_normalized_efficiency (35/나이 방향)
   → 고령에서 높은 효율 = 훨씬 강한 긍정 신호
   → 36세 수정률 70% ≠ 44세 수정률 70%

4. real_age_num (기증 난자 시 기증자 나이 사용)
   → 기증 난자 케이스에서 환자 나이는 무의미
   → 배아 품질은 기증자 나이가 결정

5. is_FET (동결 주기 여부)
   → 신선/동결 주기 패턴 자체가 다름
   → FET 마스킹: NaN이 -1보다 LGB에서 더 명확한 신호

6. 이식된 배아 수 최적화
   → 1~2개: 31% (최고), 3개: 17% (과다이식 역설)
