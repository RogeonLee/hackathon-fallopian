■ feature_engineering.py 최종 수정
================================================================

[_v3_domain에 추가] — 모든 모델 공통 적용

기존:
  v10 원본 5개 + proc 토큰 6개 + age_normalized_efficiency + is_elective_SET

새로 추가 (v10 기본 비율 7개):
  - past_preg_rate        : 총 임신 횟수 / 총 시술 횟수
  - past_birth_rate       : 총 출산 횟수 / 총 임신 횟수
  - ivf_preg_rate         : IVF 임신 횟수 / IVF 시술 횟수
  - embryo_transfer_ratio : 이식된 배아 수 / 총 생성 배아 수
  - embryo_stored_ratio   : 저장된 배아 수 / 총 생성 배아 수
  - icsi_ratio            : 미세주입된 난자 수 / 혼합된 난자 수
  - age_x_transferred     : 나이 × 이식된 배아 수

is_elective_SET 이동:
  - 기존: Group D (full only) → v3 모델에서 사용 불가
  - 변경: _v3_domain (모든 모델 공통) → 전체 모델 활용 가능

최종 피처 수:
  v3  : 46개
  full: 66개

      if not enable_cat: return df

          if not pd.api.types.is_numeric_dtype(df[c]):
              df[c] = df[c].astype('category')

■ 에러 해결: XGBoost KeyError: 'str'
================================================================

에러 메시지:
  KeyError: 'str'
  ValueError: DataFrame.dtypes for data must be int, float, bool or category
  Invalid columns: 시술 시기 코드: str, 배아수_그룹: str, ...

원인:
  _to_cat()의 select_dtypes(include=['object', 'string'])이
  pandas 2.0의 str dtype을 잡지 못함

해결:
  select_dtypes → pd.api.types.is_numeric_dtype() 사용
  숫자가 아닌 컬럼 전부 category로 변환

■ 산부인과 전문의 관점 — 도메인 지식 중요성
================================================================

"모델이 아무리 정교해도 임상적으로 의미 없는 피처를 넣으면 노이즈"

[지금까지 추가한 피처의 임상적 의미]

has_BLASTOCYST:
  5일까지 살아남은 배아는 착상 능력 자체가 다름.
  단순 이식 방법의 차이가 아니라 배아 생존력의 증거.

is_elective_SET:
  배아가 여러 개인데 1개를 선택 = 나머지를 냉동 보관할 만큼 품질이 좋다는 뜻.
  어쩔 수 없이 1개밖에 없는 경우와 근본적으로 다른 상황.

age_normalized_efficiency:
  36세 수정률 70% ≠ 44세 수정률 70%.
  고령에서 좋은 결과는 훨씬 강한 긍정 신호.

real_age_num:
  기증 난자를 쓰는 경우 환자 나이는 의미 없음.
  배아 품질은 기증자 나이가 결정.
